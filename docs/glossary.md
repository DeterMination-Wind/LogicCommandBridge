# 术语

| 术语 | 含义 |
| --- | --- |
| 端口 (port) | 被选中并绑定的那台处理器，所有指令都写进它。 |
| 端口区域 (port area) | 拖框后自动铺出来的一组处理器，指令按切片分给它们。 |
| 切片 (slice) | 部队按 `i % N` 分给 N 台处理器后，其中一台负责的那一份。 |
| 编队 (unit book) | 模组自己记录的单位列表，用于在单位被逻辑接管后仍能继续下令。 |
| 精确模式 (exact) | 单机路径：把真实单位对象注入成 `lc_uN` 常量，程序精确命中框选单位。 |
| 位置匹配 (match) | 多人路径：按“记录坐标 + 容差”在 `ubind` 扫描中认出单位，不依赖 id。 |
| 标记令牌 (token) | 多人首令给命中单位写 `@flag = token + 槽位`，保持循环只按它过滤。 |
| 槽位 (slot) | 编队网格里的格子编号；记忆在 `UnitBook.slots`，改向时沿用。 |
| 快路径 (all-of-type) | 编队等于该类型全部单位时，跳过匹配，直接 `ubind` + `ucontrol` 连发。 |
| order pass | 程序第一段：用最少指令把新目标发给全部单位。 |
| release | 程序末尾的 `ucontrol unbind`，让单位立刻回到可指挥状态。 |
| 地形夹取 (clamp) | 把落点改成该兵种最近能站的格子（海军→水、陆军→陆、空军→任意）。 |
| 保持到抵达 (hold until arrival) | 程序循环重下发 `ucontrol`，直到所有单位抵达或轮次耗尽，然后 `stop`。 |
| LogicAI 超时 | 原版行为：单位被 `ucontrol` 后 10 秒内没有新的逻辑控制就会退回普通 AI。 |
| 一次覆写 (overwrite) | 用新 mlog 文本替换处理器现有代码；链接表随之保留。 |
| `stop` | 原版停机指令；程序末尾必须写，否则 executor 会从头再跑。 |
